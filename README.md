# OSEA - Security & Code Audit Skill

OSEA is a standardized framework designed to assist in zero-trust code auditing, identifying software vulnerabilities, and implementing robust defensive architecture.

---

## Why OSEA?

* **Zero Naive Assumptions:** Evaluates codebases and network protocols through a strict zero-trust security model.
* **Structured Output:** Formats analysis into threat modeling, root-cause identification, and hardened defensive implementations.

---

## Quick Start / How to Use

1. Copy the contents of `SKILL.md`.
2. Include the skill instructions in your system prompt or environment context.
3. Submit code snippets or system architectures for defensive analysis.

---

## Standard Pipeline

When active, analysis follows a structured 4-block execution pipeline:

| Block | Focus Area | Description |
| :--- | :--- | :--- |
| **Block 1** | **THREAT MODEL** | Identifies potential entry points and memory/logic risks. |
| **Block 2** | **ANALYSIS** | Evaluates execution mechanisms and potential failure states. |
| **Block 3** | **ROOT-CAUSE BREAKDOWN** | Explains underlying technical flaws at the logic or runtime level. |
| **Block 4** | **HARDENED DEFENSE** | Provides production-ready defensive replacement code. |
